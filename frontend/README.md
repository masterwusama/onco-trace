# 前端

癌症与高致死疾病数据站的界面层：一个疾病列表页、一个逐病详情页（十一屏）、一个跨病榜页、
一个反查页（器官/症状/危险因素/靶点/药物五路共用一屏），读的就是 `api/` 那二十接口，
没有任何自己的数据。站点不做诊断，症状反查输出的也只是参考排序。

## 跑起来

两种跑法，命令都在仓库根的 `ops/` 里：

```powershell
ops\web.ps1 dev      # 开发：vite 在 http://127.0.0.1:5174，/api 代理到 127.0.0.1:8001
ops\web.ps1 build    # 生产：出 dist/（一次构建约 2 s）
```

开发时后端要另起一台：`ops\api.ps1 serve`。

生产不需要第二个端口——`ops\api.ps1 serve` 起来后直接开 `http://127.0.0.1:8001/` 就是站，
后端在同一个端口上用 `StaticFiles` 托管 `dist/` 与 `/api/*`，本来就是同源。
构建产物 `dist/` 不入库，改了源码要重新 `build` 才会反映到 8001 那个端口上。

## 结构

| 目录 | 内容 |
|---|---|
| `src/views/` | `DiseaseListView` 列表页（18 病 × 十维度量一台请求）、`DiseaseDetailView` 详情页（十一屏切换）、`CompareView` 跨病榜（度量 → 口径 → 榜）、`ReverseView` 反查页（五路按路由名分发） |
| `src/panels/` | 一屏一个面板；研究层四维共用 `ResearchPanel`，配置在 `src/lib/research.js` 里逐维给 |
| `src/components/` | 出处标签、空态、约定清单、分页器、图表盒、元信息条等共用件 |
| `src/api/client.js` | 唯一发请求的地方：一份 `API_PATHS` 清单 + 一个只发 GET 的 `get()` |
| `src/lib/` | `chart.js` echarts 公共配置、`format.js` 数字与空值、`tabs.js` 十一屏清单、`useApi.js` 单飞请求、`compare.js` 跨病榜口径轴与标签 |

路由用 hash（`/#/disease/lung`）：静态托管不需要深链接 fallback，"只注册 GET"这道护栏也就不必为它开口子。

## 界面上的几条约定

这几条不是样式偏好，是为了让页面上的一句话在库里找得到对应的一行：

- 空值一律显示「—」，不显示 0。源没给与给的是 0 是两件事。
- 空态文案来自接口的 `gaps`，前端不自己判断"这一维是不是空"——判据在度量上，只有一处。
- 每个数字带出处：行级事实挂 `provenance`（源、许可、提取方式、复核状态、装载时刻）；
  聚合出来的档（分面、组码、计数）不挂出处，页面也就不会把"这一档有 1,200 行"署给某一行。
- 拟合值与观测值画在两处：生存率 2019 年之后只有模型趋势线，图上标「观测止于 2018」。
- 单点不折线：`year=0` 是"源没给年份"的哨兵（国家级估算、年龄组构成、查询计数三类），
  这类序列只显示数值，画成线就是把一个估算说成一个趋势。
- 不在前端排序。库的序是 MySQL `utf8mb4_0900_ai_ci` 的序， JS 默认 `sort` 按码点，两者在
  这一批数据上会分岔——榜拿到什么序就显示什么序，序本身由接口在 `notes` 里自述。
- 症状按源分块显示，不合表、不跨源去重、不翻译：中文那两路只覆盖 7/18 病，并起来会让
  另外 11 病看起来也有中文名。
- 反查页五路共用一屏（`/#/reverse/…`）：疾病清单按接口给的病码序显示；危险因素反查按
  遗传 / 暴露两层分栏，两层各自的数不相加成「总数」。

## 改接口时的契约

`api/tests/run.py` 里有一道路径门禁，三个方向都钉：

1. `src/` 里出现的每一个后端路径字面量，必须在 `API_PATHS` 上；
2. `API_PATHS` 上每一条必须是后端真注册的路由；
3. 后端注册了而这里没有的路径，必须出现在 `api/tests/run.py` 的 `BACKEND_ONLY` 里并写明理由。

所以接口改了名、加了维而页面没跟上，会当场红；加了维还没画屏，就必须先写下"还没画"的理由。

前端路由统一挂在 `/#/reverse/…` 前缀下，就是为了不撞上这道门禁对后端路径字面量的扫描
（那个正则匹配 `/anatomy/` `/symptoms/` 等开头）——前端路由与后端接口是两套路径，
前者不该被当成后者要求登记。
